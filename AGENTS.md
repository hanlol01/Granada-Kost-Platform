# Repository Instructions

## Agent skills

### Issue tracker

Work items and implementation tickets are tracked in GitHub Issues. See
`docs/agents/issue-tracker.md`.

### Domain docs

This repository uses a multi-context domain-document layout. Read
`CONTEXT-MAP.md`, then the context and ADRs relevant to the assigned work. See
`docs/agents/domain.md`.

### Feature handoffs

For custom lease duration/tariff or resident checkout work, read
`docs/21-kost-management-ecosystem-overhaul/handoff/README.md` before selecting
an implementation stage. The handoff files define the approved sequence,
invariants, formulas, and completion gates.
