## Explicit Boundary Summary

- Room is not price authority.
- Room is not normal facility-assignment authority.
- Latest category price is not historical lease price.
- Resident is not occupancy; occupancy is not the lease term.
- Booking Lead is not reservation; Hold is not tenancy.
- DP is not security deposit.
- Booking Fee is a rent credit, not a security deposit.
- Booking Lead, Hold, Lead Payment Commitment, Lease, and Occupancy are distinct
  authority records; none may be inferred from another.
- The deposit ledger is not rent revenue.
- A payment without an active allocation is not settlement.
- UI state and caches are not authority.
- A report is not a maintained balance.
- A public projection is not its editorial source.
- A notification is not source-domain lifecycle authority.
- A property role is not building ownership.
- Audit, outbox, and idempotency evidence are not business-state authority.
